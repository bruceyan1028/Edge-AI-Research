按品类看：四类玩家的竞争逻辑不同

  • 通用终端SoC：手机 / PC / 汽车主控，NPU算力是唯一竞争焦点，头部高度集中且多为纵向一体化大厂（苹果、三星既做SoC也做整机）。中国厂商（海思、展锐）受出口管制或估值待验证的IPO叙事驱动；三星靠自研Exynos重夺份额、减少对高通的授权费依赖，是这一品类少见的"份额逆转"案例。
  • 专用边缘AI加速芯片：本页最拥挤、故事最丰富的品类（本页收录29家）。中国车规 / 存算一体创业公司密集融资（后摩智能、亿铸科技、知存科技），美国创业公司数量最多但也最先出清——Untether AI已停止运营、Kinara被NXP以$307M收购、Hailo从$1.2B独角兽跌至被Microchip收购，是这条赛道高风险的直接证据；地平线、爱芯元智等则已完成港股IPO，进入"以芯片+算法软硬一体"的下半场竞争。
  • 视觉 / IoT SoC：大陆厂商绝对主导（瑞芯微 / 全志 / 晶晨 / 恒玄等均已上市），受益于安防招标回暖与存储涨价周期，正向机器人 / 汽车主控延伸；台湾奇景光电（超低功耗视觉AI处理器）与联咏科技（安防SoC+DDI双主业）是此前被遗漏、此次补入的非大陆玩家，反映该品类并非中国大陆完全独占。
  • MCU / TinyML芯片：格局最稳定，被ST、英飞凌、TI、NXP、Microchip等传统MCU大厂长期把持，护城河是生态工具链而非单点算力；变化在于这些大厂正把NPU集成进主流MCU产品线（NXP MCX N、Nordic nRF54LM20B），同时中国厂商（乐鑫、兆易创新、中微半导体）借存储涨价周期加速追赶。

按国家看：四种生态形态

  • 中国（含台湾）：边缘AI加速芯片与视觉 / IoT SoC两大品类的绝对主场，车规芯片（地平线、黑芝麻）与存算一体创业公司（知存、后摩、亿铸）密集涌现；台湾联发科手机SoC出货量全球第一，奇景光电、联咏科技在视觉IoT SoC补充差异化产品线；MCU / TinyML品类正处于追赶阶段。
  • 美国：通用终端SoC（高通、苹果、英特尔、AMD）绝对领先，同时是边缘AI加速芯片创业公司最密集也最先出清的市场，NVIDIA的Jetson产品线是唯一横跨"通用算力巨头"与"边缘AI芯片"两个身份的公司。
  • 欧洲：无手机 / PC终端与OS入口，通用终端SoC品类为空；优势集中在MCU传统强区（ST、英飞凌、Nordic）与差异化架构的边缘AI创业公司（Axelera数字存算一体、Innatera神经形态、GreenWaves超低功耗RISC-V），后者普遍资本厚度弱于美中同类。
  • 其他：台湾联发科手机SoC份额全球第一；韩国DEEPX等NPU三强正冲刺IPO前最后一轮融资，三星靠自研Exynos向上游延伸；以色列Hailo的独角兽崩塌与被收购是本页最典型的边缘AI芯片退出案例。

交叉观察与口径说明

  • 纵向一体化玩家跨品类出现：NVIDIA（Tegra/Jetson）、高通（Snapdragon汽车 / XR）、三星（Exynos）、苹果（A/M系列）等公司本身也出现在模型层、方案与集成层等其他视图中，是"研发一颗芯片、覆盖多层价值链"的战略缩影，本页仅标注其L1芯片产品线，避免与其他层重复计入营收 / 市值。
  • 边缘AI加速芯片赛道的高波动性：本品类内并存IPO成功（地平线、爱芯元智）、SPAC上市后暴跌（Blaize）、独角兽估值崩塌后被收购（Hailo）、直接停止运营（Untether AI）四种截然不同的结局，是本页数据最能体现"芯片创业九死一生"的品类，建议结合各公司 f 字段的融资 / 退出细节交叉阅读。
  • 口径：① "中国"列含中国台湾企业（卡片以"台湾"标注），市值折算为美元；② 大陆企业保留人民币 / 港元，海外折算为美元；③ 子公司 / 已被收购 / 已停运（如海思、Untether AI、Hailo）标注母公司与交易 / 退出要素；④ 数据截至 2026 年 9 月初，营收多为 2025 财年或最近披露季度，市值 / 估值为 2026-09 快照，部分数据（如寒武纪市值、云天励飞市值）因第三方口径差异较大，标注"需以实时行情为准"；⑤ 本页聚焦芯片厂商本身，不含IP授权商、晶圆代工、存储器、传感器、EDA与设计服务等L1上下游配套厂商，这些环节仍只出现在全景图中。

按体量看：三类玩家的竞争逻辑不同

  • 大厂端侧小模型：本质是"模型 + OS + 分发入口"三位一体。模型多为大模型系列的小尺寸版本，开源是为抢开发者生态（Gemma、Llama、Qwen、混元），闭源则绑定自家系统入口（Gemini Nano、Apple Foundation Models、豆包端侧）。中国手机厂（华为、小米、vivo、OPPO、荣耀）几乎全部自研端侧模型，同时接入第三方模型走双轨。
  • 创业公司：靠架构创新（SSM / 线性注意力 / 液态网络）、蒸馏与压缩"以小博大"，出口是被终端厂预装、被芯片厂适配或被收购。按体量分三档：第一梯队估值百亿美元级，DeepSeek（≈5,000 亿元投前）、智谱（港股市值 ≈4,900 亿港元）、Mistral（~$13.7B）、Cohere（$7B，并购后 ~$20B）、阶跃（IPO 目标 $100 亿+）；第二梯队估值约 7–30 亿美元，Liquid AI、Sakana、Multiverse、Reka、Zyphra、Upstage、面壁（>200 亿元）；并购退出Silo AI→AMD、Hugging Face→NVIDIA、Aleph Alpha→Cohere。AMD 与 NVIDIA 同时是多家端侧模型公司的战略投资方，芯片厂正在用资本绑定模型层。
  • 垂类模态 / 算法公司：语音、视觉、生物识别是端侧 AI 最早规模商业化的领域（唤醒词、人脸、影像算法），也是上市公司最集中的一类：中国 8 家（科大讯飞市值 ≈950 亿元、商汤 ≈540 亿港元、云天励飞 ≈205 亿元；云知声、出门问问上市后市值大幅缩水），美国 2 家（SoundHound ~$3B 与 Cerence ~$0.4B 分化），日韩 3 家。正在被大模型的多模态能力冲击，应对方向是"垂类模型 + 场景数据 + 自研芯片 / 硬件"一体化（思必驰、云知声、云天励飞），或深耕车载等高门槛场景（Cerence、SoundHound、虹软）；旷视、依图等前"AI 四小龙"已多年无新融资。

按国家看：四种生态形态

  • 美国：Google / Apple / Microsoft / Meta 掌握 Android、iOS、Windows 三大 OS 入口，端侧模型 API 由它们定义；创业公司集中在新架构（Liquid、Cartesia、Zyphra）与开源平台（Hugging Face）。OpenAI 发布开放权重模型标志闭源巨头也进入端侧。
  • 中国：玩家数量最多。阿里 Qwen 与 DeepSeek 蒸馏模型成为全球端侧衍生模型的事实底座；手机厂自研模型密度全球最高；语音 / 视觉垂类形成一批上市公司（讯飞、商汤、虹软、云从、云知声、出门问问、云天励飞）。
  • 欧洲：无消费级终端与 OS 大厂，"大厂端侧小模型"一栏为空。基础模型能力集中在 Mistral；特色是压缩（Multiverse）、语音（Kyutai、Speechmatics）与 tinyML（Plumerai、Imagimob），后者多被美国 / 德国半导体厂或平台收购。
  • 其他：韩国三星、LG、Naver、Kakao 呈财阀式全栈自研并强调韩语；日本 Sakana、PFN、NTT 面向日语与机器人 / 工业边缘；加拿大 Picovoice、Cohere 聚集在语音与企业端侧；阿联酋 TII 为主权模型研究机构。

交叉观察与口径说明

  • 底座与终端模型分离：开源底座（Qwen、Llama、Gemma、DeepSeek）经蒸馏 / 量化后由终端厂、创业公司二次交付，因此"模型层"的价值正在向 L2 的压缩编译与 L5 的系统集成两端转移。
  • 模型与推理引擎绑定：阿里（MNN）、无问芯穹、Liquid AI 均同时提供模型与端侧运行时，通过"模型 + 引擎"打包提高替换成本。
  • 口径：① "大厂"指拥有终端、OS 或云分发入口的科技巨头与手机厂；"创业公司"指以通用基础模型为主业的公司，含独角兽与研究机构；"垂类"指以单一模态算法为主业的公司。② 开放权重 = 端侧代表模型权重公开可下载；部分开放 = 仅部分尺寸 / 研究许可开放；闭源 = 仅通过产品或 API 提供。③ 融资、估值、上市与并购信息基于 2026 年 9 月初公开报道核实，其中标注"进行中 / 传 / 未确认"的为媒体援引知情人士、尚无官方确认；海外公司的欧元、日元、韩元金额按融资发生时汇率折算为美元，中国公司保留人民币 / 港元；代表模型版本迭代快，引用前请以官方发布为准。④ 创业公司仅收录累计融资约 ≥1 亿美元、估值 ≥10 亿美元或有政府 / 捐赠资助的主体；RWKV、Nexa AI、Aizip、Pleias 等小体量创业公司，以及声智、Plumerai、Imagimob、Snips、ID R&D、audEERING、Useful Sensors、Fluent.ai、Fairy Devices 等小体量或已被小额收购的垂类公司未列入；Sensory、Picovoice、Innovatrics 虽无机构融资，但为自筹盈利的成熟供应商，予以保留。MiniMax、月之暗面虽融资规模大，但无端侧小模型产品，未列入。

按环节看：四类玩家的分工与差异

  • ODM / 整机与代工：是端侧 AI 的商业化主战场。手机 ODM 外包设计占全球出货 44%，头部（华勤、龙旗、立讯）高度集中；台湾五大代工在笔电与 AI 服务器代工上举足轻重，AI 服务器占广达 / 纬创营收已超七成。
  • 模组与 SoM：中国厂商主导蜂窝 IoT 模组（移远 36%、中移 11%、日海 8%），全球份额 >90%；高算力智能模组（美格 29%）是把端侧模型能力推向中长尾设备的关键载体，AI 嵌入式模组占比预计 2030 年达 25%。
  • 边缘计算硬件与平台：工业 PC、边缘 AI 盒子与数据接入平台，受益于"算力下沉"；研华、凌华等台系工控厂商绑定 NVIDIA Jetson 生态，浪潮、新华三主打中国边缘服务器与 AI 推理。
  • 行业方案与集成：行业 know-how 与客户关系壁垒。中国特色的华为昇腾 / 开源鸿蒙系统集成商（软通、中软、拓维、润和、诚迈）构成生态主力；海外由埃森哲、凯捷、WWT 等大型集成商覆盖。

按国家看：四种生态形态

  • 中国（含台湾）：数量最多、环节最全。大陆在手机 ODM（华勤 / 龙旗 / 立讯）、蜂窝 IoT 模组（全球超九成份额）与通信模组上全球领先；台湾在笔电、服务器代工与工控嵌入式（研华、凌华、宜鼎、神基）上占主导。
  • 美国：以 EMS 巨头（Flex、Jabil、Sanmina 承接云 / AI 基础设施）与模组 / SoM 上市公司（Semtech、Digi、Lantronix）为主，边缘平台创业公司多；芯片厂（高通）正通过收购向下游整合。
  • 欧洲：无手机 / PC 代工，专注工业嵌入式与 SoM 传统强区（Kontron、congatec、Toradex、SECO、u-blox）；集成商由凯捷等大型服务商代表。
  • 其他：加拿大 Celestica 在超大规模数据中心基础设施上快速崛起；日本村田在元器件与通信模组占优；印韩（Tata Elxsi、HCLTech、LG CNS、NTT DATA）以大工程服务 / 集成商身份切入。

交叉观察与口径说明

  • 硬件 > 软件的集成层：方案与集成层是"端侧 AI 落地"的最后一公里，但其价值高度集中在硬件（2026 年中国 AI 支出硬件占 74.3%），模型与软件的增值正被压缩到 L2/L3，这正是集成层利润率普遍偏低的原因。
  • AI 驱动的两极化：端侧 AI 让代工与模组厂商分化。拥抱 AI 服务器 / AI 手机的（广达、纬创、华勤、立讯、Celestica、Sanmina）营收与市值跃升；以传统笔电 / 手机组装为主的（仁宝、和硕、比亚迪电子）增长承压。
  • 芯片厂向下整合：高通收购 Edge Impulse、Arduino、Modular，英飞凌收购 Imagimob，Advent 私有化 u-blox——芯片厂与资本正在把"方案与集成层"的入口也纳入整合范围。
  • 口径：① "中国"列含中国台湾企业（卡片以"台湾"标注），市值折算为美元（汇率按 2026-09 初约 31 新台币 / 美元估算）。② 大陆企业保留人民币 / 港元，海外折算为美元。③ 子公司 / 已被收购（如 Arduino、u-blox、NTT DATA、研祥）标注母公司与交易要素。④ 数据截至 2026 年 9 月初，营收多为 2025 财年，市值 / 估值为 2026-09 快照。

按品类看：五类玩家处于完全不同的阶段

  • 人形机器人：最具想象空间、也最"早"。特斯拉 Optimus、Figure、优必选、宇树、智元、银河通用等集中在样机迭代与定点试点，商业化为"演示 + 工厂 / 整车厂 POC"，尚无确定量产曲线；处于 2024–2026 的融资长坡与 2026–2028 的量产对赌之间。
  • 工业机器人 / AGV·AMR：少数已高度成熟的存量市场。全球四大家族（发那科、ABB、安川、库卡）主导工业臂，中国以埃斯顿、汇川、新松做国产替代；AGV / AMR 是最快增长细分，极智嘉、海康机器人、快仓（中国）与 Symbotic、Locus（美国）切入仓储自动化。

  • 具身智能模型 / 核心部件：分两条不同的押注线——VLA 具身基础模型公司押"一个模型、千机千面"（Physical Intelligence、Skild、银河通用、穹彻），核心部件公司押"人形量产带来的国产替代"（绿的谐波、双环传动、兆威机电），两者互为风险对冲。

按国家看：四种生态形态

  • 中国：玩家数量全球第一，且"人形创业公司 + 消费 / 服务机器人产业 + 核心部件供应链"三位一体，是唯一能把量产叙事落到供应链成本上的地区。人形以宇树 / 智元 / 优必选为排头兵；消费与服务端的科沃斯 / 石头 / 普渡 / 大疆已是全球出货领先者。
  • 美国：几乎没有工业 / 消费机器人大型制造，但资本与基础模型最强。人形明星公司（Figure、1X、Agility、Apptronik、Tesla）+ 具身智能基础模型（Physical Intelligence、Skild）+ 机器人全栈平台（NVIDIA Isaac，英伟达既是"卖铲人"也是无数入局方的股东）。
  • 欧洲：传统强区——工业机器人四大家族占两家（ABB、库卡），协作机器人发源地（Universal Robots）。人形与具身模型例外地稀少（Neura、PAL），资本与人才进一步流向美国。

交叉观察与口径说明

  • 具身智能是"端侧 AI"在 L5 的重演：与手机 / PC 的 NPU 端侧化同理，机器人把"云端大模型"下沉为机载具身模型。因此本页是端侧 AI 产业链中算力密度最高、真正需要"端侧实时推理"的终端分支（精确操控、vSLAM、灵巧手都在机载完成）。
  • 人形核心部件复用工业机器人供应链：谐波减速器、行星滚柱丝杠、灵巧手、六维力传感器均源自工业 / 协作机器人供应链，人形放量直接利好绿的谐波、双环传动、兆威机电等国产部件厂商——这是"具身智能"最有确定性的落地支点。

  • 口径：① 本页只覆盖 L5 终端设备层中"机器人 / 具身智能"这一分支（即全景图 L5 卡片），不含手机 / PC / 汽车 / 消费 IoT 等终端；② 人形机器人尚未形成可比的量产财务口径，故不强行统一附市值 / 营收，仅标注上市状态与集团归属；③ 上市状态、集团归属与代表性产品基于 2026 年 9 月初公开信息核实，融资额逐家差异大，为避免失真只保留定性描述，具体轮次与金额以公司官方披露为准；④ 入选标准以"自主品牌整机 / 具身模型"为核心，代工、纯部件配套（除已品牌化的减速器 / 丝杠龙头）、研究机构与仅做展示的样机不单列。

按品类看：AI 眼镜是最活跃的新变量

  • XR 头显：Apple Vision Pro 定义高端空间计算形态但出货有限，Meta Quest 以性价比占据消费 VR 大部分市场；中国字节 PICO、三星 Moohan（联合 Google / 高通）跟进 MR 赛道，整体仍处于内容生态培育期。
  • AI 眼镜：2023–2026 年增长最快的新品类，Meta Ray-Ban 系列证明"轻量 AI + 拍摄 + 语音"的可行商业模式；中国厂商（Rokid、雷鸟、蜂巢科技、小米、百度）密集跟进，多数走"无显示 AI 音频眼镜"到"轻量光波导显示"的渐进路线。
  • 智能手表：成熟品类，Apple Watch 与华米、小米生态链主导出货量；健康监测（心率 / 血氧 / ECG）与运动数据是核心卖点，AI 端侧化体现在异常检测与语音助理增强。
  • 智能耳机：AirPods 定义品类天花板，主打空间音频、主动降噪与实时翻译；中国品牌（华为、小米）与传统 Hi-Fi 厂商（Bose、Sony）在降噪算法与端侧语音芯片上竞争。
  • 健康可穿戴：Oura、Whoop 等专注睡眠 / 恢复指标的垂类硬件公司崛起，与手表 / 手环形成差异化；核心壁垒是传感器算法而非算力。

按国家看：三种生态形态

  • 中国：AI 眼镜创业公司全球最密集（Rokid、雷鸟创新、蜂巢科技、INMO），叠加手机厂商（小米、百度、华为）快速跟进；智能手表 / 手环出货量全球领先（华米、小米生态链），光学与传感器供应链最完整。
  • 美国：Apple 与 Meta 分别以"高端生态锁定"和"轻量走量 + 广告数据"两种打法定义品类；Google 通过与三星、Warby Parker 合作重回 XR/眼镜赛道；健康可穿戴创业公司（Oura、Whoop）活跃。
  • 欧洲：运动 / 户外可穿戴传统强区（Garmin 美企但欧洲市场深耕、Polar 芬兰、Suunto 芬兰），XR 与 AI 眼镜领域缺少本土巨头，多依赖美系生态。
  • 其他：三星走"手表 + 耳机 + XR 头显"全栈自研路线并与 Google/高通联合推出 Moohan；日本在精密光学、传感器与显示面板供应链上话语权仍强，但终端品牌参与度低。

交叉观察与口径说明

  • AI 眼镜是"端侧 AI"在可穿戴品类的最新落点：相比手表 / 耳机的成熟形态，AI 眼镜把摄像头 + 麦克风 + 端侧多模态模型首次整合进日常佩戴设备，是本页增长最快、竞争最激烈的细分。
  • 健康监测算法与端侧推理深度绑定：心率异常检测、睡眠分期、跌倒检测等均需在低功耗 MCU / 小型 NPU 上实时运行，是可穿戴品类"端侧 AI"最早规模化落地的场景，早于生成式 AI 叙事。
  • 生态锁定 vs 硬件性价比两条路线并行：Apple / Meta 依靠系统生态与内容锁定用户，中国厂商更多以硬件迭代速度与价格竞争抢占增量市场，尤其在 AI 眼镜这一新兴品类。
  • 口径：① 本页只覆盖 L5 终端设备层中"可穿戴 / XR"这一分支（即全景图 L5 卡片），不含手机 / PC / 汽车 / 机器人等终端；② 归属地按公司总部认定；③ 上市状态、代表产品基于 2026 年 9 月初公开信息核实，具体参数与融资以官方披露为准；④ 入选标准以"自主品牌终端整机"为核心，纯代工与仅做展示的概念机不单列。

按品类看：录音硬件最成熟，自动化操作硬件是最新变量

  • AI Pin / 挂件录音：目前唯一跑通商业模式的子品类，且仍在持续涌入新玩家。Plaud 以"满足录音刚需"为切口做到数亿美元营收并保持盈利；Genspark 用更轻薄的卡片形态 SecondBrain Note 正面对标 Plaud；Limitless、Bee 先后被 Meta、Amazon 收购整合进大厂生态；Friend、Omi、Nirva 等仍在探索"陪伴 / 情绪记录 vs 隐私"的产品定位分野。
  • 无屏 AI 助理：最具想象力也最难落地的一类。Humane AI Pin 因体验不及预期被 HP 收购資產、硬件停售；Rabbit r1 靠持续软件迭代维持运营但尚未证明"手机之外"的独特价值；OpenAI（联合 Jony Ive 的 io 团队）、Motorola 与国产新秀 Violoop（BVIO Tech）正押注"无屏智能音箱 / 挂件 / 硬件级自动化操作"作为下一轮尝试。
  • AI 陪伴玩具：中国增长最快的消费级细分，跃然创新 BubblePal/CocoMate、萌友智能 Ropet 均已批量出货并持续融资；印度 Miko、新加坡 Lingverse iKairos（可拆卸模块、居家变桌面机器人）与日本 Sony aibo / Casio Moflin 代表儿童教育与情感陪伴多条不同路线。
  • AI 翻译硬件：最早商业化、格局最稳定的细分。科大讯飞、时空壶、日本 Pocketalk（原 Source Next）与波兰 Vasco 分占中日欧市场，核心竞争力是离线转写准确率与多语种覆盖，而非算力堆叠。
  • 开发套件 / 极客硬件：本页玩家最密集、也最容易被忽略的一层——它不是消费品，而是其他四个品类的共同底座。NVIDIA（Jetson Orin Nano Super 249 美元 / 67 TOPS，DGX Spark 桌面一体机）与树莓派（AI HAT+ 系列，最高 40 TOPS）构成事实标准；中国厂商则走"极低成本 + 自主路线"，嘉楠 CanMV-K230（249 元、全球首款 RISC-V Vector 1.0 商用 SoC）、瑞莎 ROCK 5、华为昇腾 Atlas 200I DK A2（1,999 元）各据一角；乐鑫 ESP32-S3/P4 与 MIT 开源项目小智 AI 更是国内绝大多数 AI 玩具与语音助理硬件的共同上游。

按国家看：三种打法

  • 中国：供应链与制造成本优势最明显，AI 玩具与录音硬件两条线均已跑出盈利或规模化出货的公司（跃然创新、萌友智能、科大讯飞、时空壶、出门问问）；开发套件层更是本页中国玩家最密集的一块——嘉楠、乐鑫、矽递、瑞莎、华为昇腾、M5Stack 与开源项目小智 AI 共同构成一条从芯片、模组到参考设计的完整本土供给链，这也是国内 AI 玩具能快速起量的根本原因。
  • 美国：资本与媒体关注度最高、但淘汰率也最高——Humane 停产、Limitless 被收购、Rabbit 长期"叫好不叫座"；Plaud、Genspark、Nirva 是少数例外，反而是"轻量刚需切口 + 自负盈亏"的打法跑通；OpenAI 用 65 亿美元收购 io 押注下一代无屏助理。真正稳定获利的其实是卖"铲子"的 NVIDIA——Jetson 模组同时支撑着松果派、矽递 reComputer 等中外产品。
  • 欧洲：消费级几乎空白（仅波兰 Vasco 翻译硬件），但在开发套件层反而有两张王牌：英国树莓派（2024 年伦交所上市，AI HAT+ 系列）与意大利 Arduino（2025 年 10 月被高通收购），是欧洲少有的具备全球影响力的硬件品牌。
  • 其他：日本（Pocketalk 翻译机、Sony aibo / Casio Moflin 陪伴机器人）以存量成熟品类为主；印度 Miko、Aiden Hardware 与新加坡 Lingverse 则代表新兴市场在儿童陪伴、自动化硬件等细分上的新尝试，鲜有新兴 AI Pin 类创业公司。

交叉观察与口径说明

  • "全新品类不与存量正面竞争"是唯一验证过的生存法则：Plaud Note 以"苹果手机无法本地录音"这一空白需求切入，AI 玩具、翻译硬件同样是绕开手机 / 智能音箱存量竞争的细分市场；反之，试图"替代手机"的 Rabbit r1、Humane AI Pin 均遭遇"有什么手机做不到"的质疑，导致大规模退货甚至停产。
  • 大厂收购是本轮周期的主要退出路径：Meta 收购 Limitless、Amazon 收购 Bee、HP 收购 Humane 资产，均发生在 2025 年内；说明独立硬件创业公司即便验证了产品形态，也难以独立走完"生态 + 数据 + 分发"的完整闭环，最终并入大厂生态是较常见结局。
  • 2026 年新变量：从"戴在身上"转向"插在设备上"的硬件级自动化操作：Violoop、Aiden Hardware 代表的一类新硬件不再自己收音 / 显示，而是让 AI 直接接管手机 / 电脑屏幕执行操作，说明"AI 原生硬件"的边界正在从可穿戴 / 挂件继续向外扩展；OpenAI + Jony Ive 团队、Motorola 相继入局无屏助理 / 挂件形态，也说明这一赛道尚未被判定为"死掉的品类"，创业公司的窗口期与巨头入场节奏高度相关。
  • 口径：① 本页只覆盖 L5 终端设备层中"AI原生新硬件"这一分支（即全景图 L5 卡片），不含手机 / PC / 汽车 / 机器人 / 可穿戴（含 AI 眼镜，已单列入可穿戴页）等终端；② 归属地按公司总部认定，BVIO Tech（Violoop）为中国团队创立、面向海外首发，仍按团队总部计入中国；③ 上市状态、代表产品与融资信息基于 2026 年 9 月初公开信息核实，具体轮次与金额以公司官方披露为准；④ 入选标准以"独立品牌整机"为核心，纯代工方案与仅停留在概念 / 原型阶段（如尚未量产的 OpenAI 音箱、Motorola Project Maxwell、Violoop、松果派）单独标注未上市状态，不作为成熟产品夸大表述。
